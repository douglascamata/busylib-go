# Changelog

All notable changes to busylib-go are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions are the
Go module tags, which follow [Semantic Versioning](https://semver.org/).

Entries are written as fragments in `.changes/unreleased/` with each change and
batched into a release with [changie](https://github.com/miniscruff/changie).
The Upstream section records moves of the vendored protobuf schemas, the
emulator revision, or the firmware version the client was checked against.

busylib-go is an unofficial project and is not affiliated with, endorsed by,
or supported by Flipper Devices or BUSY.
